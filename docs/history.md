## 見えた傾向

**両モデルとも、条件を総当たりで確かめる論理パズルを間違えた。** 3 つの箱と宝では、6 回すべて「B」と答えた。宝が B にあると A と C の札が両方本当になり、「本当の札はちょうど 1 枚」に反するので、正解は C しかない。答えは出力 6 トークンで、推論を書かずに記号だけを返していた。設問の「記号だけを答えて」が、推論の過程を省かせた可能性がある。

**mini は数え上げで答えが揺れ、nano は揺れなかった。** 3 でも 4 でも割り切れない数を数える問題で、mini は 13・10・13 と答えた。10 と答えた回は該当する数を 10 個並べており、13 は数え間違いと見る。nano は 3 回とも 10 だった。

**nano は説明が長く、mini は答えだけを返しがち。**（訂正: 本番の 61 問では出力トークンの合計が mini 17,959、nano 17,124 でほぼ同じになり、この傾向は成り立たなかった。[speed-and-limits.md](speed-and-limits.md)） 試しの 6 問で使った出力トークンの合計は、nano が 2,033、mini が 893 だった（3 つの答えの合計）。数え上げの問題では nano 930 トークンに対し mini 365 トークン。「数だけを答えて」と指示しても、nano は途中の計算を書いてから答えた。

**mini は応答が遅い。** Chat の所要時間の中央値は、mini 610 ms、nano 316 ms。数え上げの問題では mini が 4,774 ms かかり、出力が少ないのに nano（1,258 ms）より遅かった。

**温度 0.7 での答えの多様さに差がある。** 架空の人物を JSON で出させる問題で、mini は 3 回とも違う名前（英語名 1 回を含む）を出し、nano は 3 回とも同じ名前だった。

**rerank は順位は正しいが、スコアの差がごく小さい。** 上位 2 件のスコアが 0.99999976 と 0.99052548 のように、どちらも 1 に近い。順位づけには使えるが、スコアの値を関連の強さのしきい値に使うのは難しそうである。

**Chat 以外のモデルは速い。** 所要時間の中央値は embedding 124 ms、rerank 121 ms、translate 201 ms、guard 275 ms で、どれも Chat より速い。

**レート制限まわりは文書どおり。** 応答ヘッダーにレート制限の情報も `Retry-After` も無かった。26 回送って、429 は 0 回だった。
