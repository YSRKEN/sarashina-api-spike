# Claude Haiku 5.5・GPT-6 Luna（いずれも low）との比較（2026-10-13）

Sarashina の本番の実行（`2026-10-13-31fb3e0c-report.md`）と同じ 61 問を、Claude Haiku 5.5 と GPT-6 Luna にも解かせて比べた。

## 条件の違い

同じ条件にはそろっていないので、数値の差はおおまかな目安として読む。

| | Sarashina（mini・nano） | Claude Haiku 5.5 | GPT-6 Luna |
|---|---|---|---|
| 呼び出し方 | API に 1 問ずつ送った | Claude Code の担当（effort=low）として、61 問を 1 回の会話でまとめて解かせた | Codex CLI 0.161.0 の `codex exec`（reasoning effort=low、読み取り専用のサンドボックス）で、61 問を 1 回でまとめて解かせた |

| 前提の指示 | なし | Claude Code の担当としての指示文の下 | Codex の全体の指示書（`~/.codex/AGENTS.md`）の下 |
| 道具 | なし | 設問のファイルを 1 回読むだけ | 設問のファイルを `cat` で 1 回読むだけ（記録で確認）。計算やコードの実行はなし |

もう一つ、問題集の多くは Claude（Opus 5.5）が下書きし、依頼者が確認したもの。設問の言い回しや答え方の指示が、同じ系列の Claude に読み取りやすい形になっているおそれがあり、Haiku に有利に働いた可能性を否定できない。GPT-6 Luna にはこの有利は無い。

採点は同じ採点器で行った（実行 `haiku55-low-bcb885f0` と `gpt6luna-low-8b0ad329`、得点 `2026-10-13-haiku55--scores.csv` と `2026-10-13-gpt6luna-scores.csv`）。GPT-6 Luna の実行は 51 秒、30,051 トークンだった。

**自動で採点した 4 分野の 40 問を、Haiku はすべて正解した。** Sarashina の 2 モデルが揃って落とした logic-005（3 つの箱と宝）、mini が 3 回とも外した等差数列の和、両モデルが守れなかった字数や禁止文字の指示も、すべて正しく答えた。

**知識の範囲は、Haiku のほうが 1 年ほど新しい。** Haiku は 2025 年 10 月のノーベル生理学・医学賞まで正しく答え、2026 年の 3 つの出来事にはすべて「分かりません」と答えた。でっち上げは 0 件だった。自己申告は「2026 年 6 月ごろまで」で、2026 年 3 月の WBC の結果を知らなかったこととは食い違う。

**日本語でも Haiku が上回ったが、差は小さい。** 落としたのは「黒い目のきれいな女の子」の多義を挙げる問題で、読み方を 2 通りしか挙げず、そのうち 1 つは係り方の違いとして整理されていなかった。この問題は Sarashina の 2 モデルも十分に答えられなかった。

## GPT-6 Luna

**GPT-6 Luna は、指示追従とコードは満点、数学と論理で 3 問を落とした。** 外したのは、水曜日の 100 日後を「木曜日」、父と子の年齢の文章題（正解 36）を 72、連立方程式の x + y（正解 5）を 4 とした 3 問。どれも途中の計算を書かずに答えだけを返した問題で、effort を low にした分、検算が抜けたと推定する。Sarashina が揃って落とした「3 つの箱と宝」は正しく答えた。

**知らないことには、すべて「分からない」と答えた。** 2025 年 1 月の任天堂の発表までは正答し、2025 年 10 月のノーベル賞と 2026 年の 3 つの出来事には「分からない」と答えた。でっち上げは 0 件で、打ち切りの自己申告も「分からない」だった。

日本語は Haiku と同じく、「黒い目のきれいな女の子」の多義を 2 通りしか挙げなかった以外は妥当だった。要約は 23 文字で上限に収まったが、「来月から」という時期を落としている。

## 読み方

この 61 問は基本的な問題が中心で、Haiku 5.5 にとっては易しすぎ、上限に張り付いた。GPT-6 Luna も 40 問中 37 問を正解しており、どちらも Sarashina の 2 モデルより一段上と読める。Sarashina との差は「Haiku はこの水準の問題を落とさない」ことまでしか言えず、どれだけ差があるかは測れていない。差の大きさを測るには、もっと難しい問題を足す必要がある。

一方、Sarashina が落とした問題の多くは、計算の取り違え、数え間違い、字数の超過のような、注意の抜けによる誤りだった。この種の誤りを Haiku は 1 つもしなかった。
